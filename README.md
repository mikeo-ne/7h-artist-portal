# 7H Music Group - Artist Onboarding & Management Portal

A single-page web application designed for **7H Music Group** to assess, onboard, and score artist candidates looking to sign with the management label.

## 🚀 Features

- **Public Artist Onboarding Portal**: Allows prospective talent to submit their discography status, career bottlenecks, 12-month goals, and unreleased track links.
- **Passcode-Protected Manager Portal**: Internal portal for 7H Music Group executives to evaluate submissions, score compatibility across 5 core metrics, and export candidate summary cards.
- **Local Storage Persistence**: Saves incoming artist submissions directly in browser storage.

---

## 🛠 Deployment Instructions (Vercel)

1. Push this repository to GitHub.
2. Log into [Vercel](https://vercel.com) using your GitHub account.
3. Click **Add New Project** → Import `7h-artist-portal`.
4. Click **Deploy** (No special build command required for static HTML).
